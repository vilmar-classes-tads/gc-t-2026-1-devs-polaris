# Changelog

Todas as mudanças relevantes deste projeto serão documentadas neste arquivo.

## [v0.1.0] - Primeira Entrega Parcial

### Added

#### Módulo de Cadastro de Usuários (Issue 0)

* Cadastro de servidores.
* Interface de console.
* Validação de CPF único.
* Validação de e-mail único.
* Validação de senha.
* Atribuição automática de papéis padrão.
* Tratamento de exceções.
* Refatoração para reutilização de código.
* Remoção da interface gráfica.

#### Módulo de Editais (Issue 1)

* Cadastro de edital.
* Edição de edital.
* Listagem de editais.
* Validação do período de submissões.
* Validação do período de avaliações.
* Permissões de administrador.
* Validação de unicidade do edital.
* Tratamento de exceções do edital.
* Correção das validações do edital.

### Notes

* Primeira release do projeto.
* Entrega correspondente às funcionalidades das Issues 0 e 1.
